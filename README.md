# Parallax Exploration

A visually immersive parallax scrolling experience featuring multi-layered environmental elements including birds, deer, mountains, and celestial bodies.

## Features
- Multi-layered parallax scrolling effects.
- Background-removed high-quality assets for seamless depth.
- Smooth CSS and JavaScript transitions.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Assets
Includes various environmental layers:
- Sky, Stars, and Space
- Mountains and Soil
- Flora and Fauna (Trees, Birds, Deer)
- Deep Earth elements (Magma, Roots)

## Deployment
Deployed on Vercel.
